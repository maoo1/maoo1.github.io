# AHHHHH
---

This project utilized an ESP32 TTGO T-Display that displayed a generated visual going "ahhhhh" of varying forms and intensities via. procedural randomness. Click the image below to watch a video demo: 

[![Watch demo](/blog/aah/ahh-still-frame.png)](https://youtube.com/shorts/dEwTF94ChPs)

February was a really busy month, and I had a lot going on. I became swamped with planning multiple events for Chinese New Year and managing all the moving parts was incredibly hard. I was feeling frustrated all the time, and I was looking for some type of release. When I was thinking about this project and what artistic direction I wanted to take, I couldn't help but feel the frustration and craziness from other parts of my life seep in, so I let what I created reflect those exact feelings.

---
# Thought Process


From the very beginning, I knew my text was going to be some version of a scream, and "ahhh" just felt the most appropriate. It captured my feelings the best. However, what I was really struggling with was figuring out how to communicate the experience of this feeling. I was originally thinking about having a flashing red background, but it felt too intense for feelings of frustration that came and go. So I settled for a plain black background with white specks that flicked around to convey the flexibility of intensity. Additionally, I knew that having the same "ahh" felt too flat. There needed to be some variety. I decided to randomly generate the "ahhs," so they would scale up and up. In the beginning, there may only be a couple lower case letters and minimal "a's" and "h's," but as it went on for longer, the scream would also get longer, letters becoming capitalized, and exclaimations were inbetween. When the scream would reach a boiling point, the letters would randomly glitch. I went with this slower build up to mirror the way my feelings were slowly bubbling over. Like seriously, the 2 weeks leading up to the installation were so hectic, it was just a lot to keep track of. Additionally, I thought about it in the context of an installation rather than just a simple assignment. I knew that the display was likely to rotate in circles because of the set up, so it was important that I got the frame rate just right. I wanted the audience to be able to see that the display had cycled through various screams by the time it rotated into view again, so I played around with different frame rates. I wanted to find something that wasn't too slow but also wasn't crazy fast and chaotic. 

During this process, I didn't have too many technical difficulties. The biggest issues probably happened when I was first familiarizing myself with the technology. I didn't understand that the code existed on the hardware itself, so everytime I had to flash the code onto it again. This was very confusing at first because I kept changing my code thinking it was a code error. Additionally, I was having port issues, but that was because my laptop has multiple usb-c ports, and I was plugged into the wrong one.

# Reflections


I thought it was really interesting exploring this medium as a means of processing my feelings, specifically frustration and anger. Usually, I would just journal or do something physical to release the energy, but sitting there typing on my computer fine-tuning roughly the number of "a's" and "h's" that captured the vibe was really funny and surprisingly helpful in processing some the emotions. Overally, I'm really happy with the way it turned out!
